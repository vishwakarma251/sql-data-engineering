# SQL Window Functions — GROUPS BETWEEN

## 1. GROUPS BETWEEN kya hai?

`GROUPS BETWEEN` window frame ko **peer groups** ke basis par define karta hai.

Same `ORDER BY` value wale rows ek **peer group** banate hain.

Example:

| Student | Marks |
|---|---:|
| A | 10 |
| B | 20 |
| C | 20 |
| D | 20 |
| E | 30 |
| F | 40 |
| G | 40 |

With:

```sql
ORDER BY Marks
```

Peer groups:

```text
G1 = 10
G2 = 20, 20, 20
G3 = 30
G4 = 40, 40
```

### Golden Rule

> `GROUPS` mein groups ko count karo, aur selected groups ki **saari rows** frame mein include karo.

---

## 2. Basic Syntax

```sql
GROUPS BETWEEN start AND end
```

Examples:

```sql
GROUPS BETWEEN 1 PRECEDING AND CURRENT ROW
```

```sql
GROUPS BETWEEN CURRENT ROW AND 1 FOLLOWING
```

```sql
GROUPS BETWEEN 2 PRECEDING AND 2 FOLLOWING
```

---

## 3. PRECEDING

`PRECEDING` ka matlab hai current group se **peeche ke peer groups**.

Example:

```text
G1 = 10
G2 = 20,20
G3 = 30,30,30   ← current
G4 = 40
```

```sql
GROUPS BETWEEN 1 PRECEDING AND CURRENT ROW
```

Frame:

```text
G2 + G3
```

Values:

```text
20,20,30,30,30
```

### Important

`1 PRECEDING` ka matlab **1 row pehle** nahi hai.

It means:

> Current group se **1 peer group pehle**.

---

## 4. CURRENT ROW

`GROUPS` frame mein `CURRENT ROW` current **peer group** ko represent karta hai.

Example:

```text
G1 = 10
G2 = 20,20
G3 = 30,30,30   ← current group
```

```sql
GROUPS BETWEEN CURRENT ROW AND CURRENT ROW
```

Frame:

```text
30,30,30
```

Sirf current physical row `30` nahi, balki **poora current peer group** include hota hai.

---

## 5. FOLLOWING

`FOLLOWING` ka matlab hai current group se **aage ke peer groups**.

Example:

```text
G1 = 10
G2 = 20,20
G3 = 30,30,30   ← current
G4 = 40
G5 = 50,50
```

```sql
GROUPS BETWEEN CURRENT ROW AND 1 FOLLOWING
```

Frame:

```text
G3 + G4
```

Values:

```text
30,30,30,40
```

---

## 6. PRECEDING + FOLLOWING Together

Example:

```text
G1 = 10
G2 = 20,20
G3 = 30,30,30   ← current
G4 = 40
G5 = 50,50
```

Query:

```sql
GROUPS BETWEEN 1 PRECEDING AND 2 FOLLOWING
```

Frame:

```text
G2 + G3 + G4 + G5
```

Values:

```text
20,20,30,30,30,40,50,50
```

### Formula

```text
N PRECEDING
+
CURRENT GROUP
+
M FOLLOWING
```

---

## 7. Complete Example with SUM()

```sql
SELECT
    student,
    marks,
    SUM(marks) OVER (
        ORDER BY marks
        GROUPS BETWEEN 1 PRECEDING AND CURRENT ROW
    ) AS group_sum
FROM students;
```

Data:

| Student | Marks |
|---|---:|
| A | 10 |
| B | 20 |
| C | 20 |
| D | 20 |
| E | 30 |
| F | 40 |
| G | 40 |

Groups:

```text
G1 = 10
G2 = 20,20,20
G3 = 30
G4 = 40,40
```

Results:

| Student | Marks | Frame | SUM |
|---|---:|---|---:|
| A | 10 | G1 | 10 |
| B | 20 | G1 + G2 | 70 |
| C | 20 | G1 + G2 | 70 |
| D | 20 | G1 + G2 | 70 |
| E | 30 | G2 + G3 | 90 |
| F | 40 | G3 + G4 | 110 |
| G | 40 | G3 + G4 | 110 |

Notice:

> Same peer group ke rows ko same frame milta hai.

---

## 8. GROUPS vs ROWS vs RANGE

Short reference:

| Frame | Kis basis par? |
|---|---|
| `ROWS` | Physical row position |
| `RANGE` | `ORDER BY` value/range |
| `GROUPS` | Peer groups |

### One-line memory trick

```text
ROWS   → Position
RANGE  → Value
GROUPS → Group
```

---

## 9. Important Interview Trap

Data:

| ID | Score |
|---:|---:|
| 1 | 10 |
| 2 | 20 |
| 3 | 20 |
| 4 | 30 |
| 5 | 30 |
| 6 | 40 |

Current row = ID 4, Score = 30.

### ROWS

```sql
ROWS BETWEEN 1 PRECEDING AND CURRENT ROW
```

Frame:

```text
20,30
```

Because `ROWS` physical row position count karta hai.

### RANGE

```sql
RANGE BETWEEN 1 PRECEDING AND CURRENT ROW
```

Score = 30.

Value range:

```text
29 through 30
```

Isliye frame:

```text
30,30
```

20 include nahi hoga.

### GROUPS

```sql
GROUPS BETWEEN 1 PRECEDING AND CURRENT ROW
```

Groups:

```text
G1 = 10
G2 = 20,20
G3 = 30,30
```

Frame:

```text
20,20,30,30
```

### Interview takeaway

```text
ROWS   → physical rows
RANGE  → values
GROUPS → peer groups
```

## 10. Data Engineering mein Use

`GROUPS BETWEEN` tab useful hota hai jab:

- `ORDER BY` mein duplicate values hoti hain.
- Same-value rows ko ek logical unit treat karna ho.
- Frame ko individual rows ke bajay peer groups ke basis par move karna ho.

Example:

```text
Date       Sales
01-Jan     100
01-Jan     200
02-Jan     150
03-Jan     300
03-Jan     100
```

Yahan:

```text
G1 = 01-Jan → 100,200
G2 = 02-Jan → 150
G3 = 03-Jan → 300,100
```

Agar requirement ho:

> Current date group aur previous date-group(s) ko include karna.

Toh `GROUPS` naturally fit ho sakta hai.

## 11. Interview Importance

Data Engineering interviews ke liye approximate priority:

| Topic | Importance |
|---|---|
| `ROWS BETWEEN` | Very High |
| `RANGE BETWEEN` | High |
| `GROUPS BETWEEN` | Medium-Low |

`GROUPS` ko completely skip nahi karna chahiye, lekin iske bahut saare patterns ratne ki zarurat nahi hai.

Most important interview question:

> `ROWS`, `RANGE`, aur `GROUPS` mein kya difference hai?

Answer:

```text
ROWS   → physical row position
RANGE  → ORDER BY value/range
GROUPS → peer groups
```

---

## 12. Quick Revision

### `GROUPS` ka core concept

```text
1. ORDER BY ke basis par peer groups identify karo.
2. PRECEDING/FOLLOWING se groups count karo.
3. Selected groups ki saari rows frame mein include karo.
```

### Golden Rule

> **GROUPS = group count karo → selected groups ki ALL rows include karo.**

### Memory Trick

```text
ROWS   = rows count
RANGE  = values dekho
GROUPS = groups count
```
