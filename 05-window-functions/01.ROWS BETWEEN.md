# ROWS BETWEEN (Window Functions)

## Prerequisites

Before learning `ROWS BETWEEN`, you should already know:

- GROUP BY
- HAVING
- Self Join
- Rolling 24-hour Window using Self Join
- PARTITION BY
- ORDER BY inside OVER()
- Running Total

---

# What is ROWS BETWEEN?

`ROWS BETWEEN` tells SQL **how many rows around the current row** should be included in the window.

Think of every row as having an invisible moving window.

As the current row changes, the window also moves.

This is why it is called a **Sliding Window**.

---

# Real-Life Analogy

Imagine students sitting in a classroom.

| Roll No | Marks |
| ------: | ----: |
|       1 |    50 |
|       2 |    60 |
|       3 |    70 |
|       4 |    80 |
|       5 |    90 |

Teacher says:

> Add your marks and the previous 2 students' marks.

For Roll 4:

```
50

60 ← Included

70 ← Included

80 ← Current

90
```

Total:

```
60 + 70 + 80
```

Notice that 50 is no longer included.

The window moved.

---

# Syntax

```sql
ROWS BETWEEN start
AND end
```

Example:

```sql
ROWS BETWEEN 2 PRECEDING
AND CURRENT ROW
```

Meaning:

- Current row
- Previous 2 rows

---

# PRECEDING

PRECEDING means:

> Look behind (previous rows)

Example:

```sql
ROWS BETWEEN 1 PRECEDING
AND CURRENT ROW
```

Current Row = 80

Window:

```
70 ← Previous row

80 ← Current row
```

Total:

```
70 + 80
```

---

# FOLLOWING

FOLLOWING means:

> Look ahead (next rows)

Example:

```sql
ROWS BETWEEN CURRENT ROW
AND 1 FOLLOWING
```

Current Row = 80

Window:

```
80 ← Current

90 ← Next row
```

Total:

```
80 + 90
```

---

# PRECEDING + FOLLOWING Together

Example:

```sql
ROWS BETWEEN 1 PRECEDING
AND 1 FOLLOWING
```

Current Row = 70

Window:

```
60 ← Previous

70 ← Current

80 ← Next
```

Total:

```
60 + 70 + 80
```

---

# Bigger Window

Example:

```sql
ROWS BETWEEN 2 PRECEDING
AND 2 FOLLOWING
```

Current Row = 70

Window:

```
50 ← 2 Previous

60 ← 1 Previous

70 ← Current

80 ← 1 Next

90 ← 2 Next
```

Maximum rows:

```
2 Previous
+ Current
+ 2 Next

= 5 Rows
```

---

# Boundary Rule (Very Important)

SQL never throws an error if requested rows do not exist.

Example:

Current Row = First Row

```sql
ROWS BETWEEN 2 PRECEDING
AND CURRENT ROW
```

There are no previous rows.

SQL simply uses the available rows.

Example:

```
50
60
```

Not:

```
ERROR
```

---

Similarly,

Current Row = Last Row

```sql
ROWS BETWEEN CURRENT ROW
AND 2 FOLLOWING
```

If following rows do not exist,

SQL simply ignores them.

---

# Golden Rule

Window Functions never fail because of missing surrounding rows.

They always use:

> **Only the available rows.**

---

# Sliding Window

Every row gets its own window.

Example:

Current = 50

```
50
60
70
```

Current = 60

```
50
60
70
80
```

Current = 70

```
50
60
70
80
90
```

Current = 80

```
60
70
80
90
```

Current = 90

```
70
80
90
```

The window keeps moving with the current row.

---

# Running Total vs Moving Total

Running Total

```
50

50+60

50+60+70

50+60+70+80

50+60+70+80+90
```

Never drops old rows.

---

Moving Total

```
50

50+60

50+60+70

60+70+80

70+80+90
```

Old rows leave the window.

---

# Key Takeaways

- `PRECEDING` = Previous rows
- `CURRENT ROW` = Current row
- `FOLLOWING` = Next rows
- Window moves with every current row
- SQL never throws an error for missing surrounding rows
- SQL always uses only available rows
- `ROWS BETWEEN` works with physical row positions
